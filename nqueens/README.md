# N Queens

`0-nqueens.py` résout le problème des N reines avec un algorithme de backtracking.

## Usage

```bash
./0-nqueens.py N
```

`N` doit être un entier supérieur ou égal à 4.

Le programme affiche toutes les solutions, une par ligne, sous la forme d’une liste de coordonnées `[row, column]`.
